# 03 · 交互设计

> 状态：生效中 ｜ 更新：2026-09-25
> 本文件描述拾刻"长什么样、怎么操作"。括号中的 S 编号对应 [02-阶段路线图](02-阶段路线图.md) 中的能力，说明该交互在哪个阶段交付。

## 1. 信息架构

```
拾刻（菜单栏应用，没有 Dock 图标）
├── 菜单栏图标 ── 左键：面板；右键：菜单
├── 面板（主界面，点击外部即收起）
│   ├── 顶栏：模式切换「便签｜待办」、搜索、更多（⋯）
│   ├── 快速输入框（待办模式下附带时间识别提示）
│   ├── 列表（随模式切换）
│   └── 提示条（撤销、错误、通知权限）
├── 桌面卡片（每张钉出的便签一张，可有多张）
├── 设置窗口（独立窗口）
├── 首次启动引导（S4-08）
└── 系统通知（S2-04）
```

## 2. 菜单栏图标

- **图标：**单色模板图标，自动适配菜单栏深浅色。阶段 0 使用系统符号 `note.text`，正式图标在阶段 4 设计。
- **计数（S2-08）：**图标右侧显示数字，数字为 0 时不显示。显示什么由设置决定（不显示 / 逾期+今天 / 全部未完成）。
- **左键：**打开或收起面板。
- **右键菜单**（最终形态，各项在对应阶段出现）：

```
打开拾刻
────────────
隐藏所有卡片 / 显示所有卡片      (S3-09)
────────────
设置…                          ⌘,
开机自启                  ✓     (S1-08)
关于拾刻
────────────
退出拾刻                        ⌘Q
```

## 3. 面板

| 要素 | 规格 |
|---|---|
| 尺寸 | 默认 360×520 pt；最小 300×360；最大 600×1000，且不超出所在屏幕的可见区域；右下角拖动把手调整；尺寸被记住（S1-01） |
| 背景 | 系统弹出面板的默认材质（macOS 26 及以上为 Liquid Glass 外观） |
| 顶栏 | 左侧：分段控件「便签｜待办」，待办上显示数字角标（S2-08）；右侧：搜索按钮（S2-09）、更多按钮 ⋯（设置…、隐藏/显示所有卡片、退出拾刻） |
| 输入区 | 快速输入框；待办模式下，其下方是时间识别提示（S2-01） |
| 列表 | 占满剩余空间，可滚动 |
| 提示条 | 撤销提示从底部浮出；错误和权限提示显示在顶栏下方 |

**打开与收起：**打开时焦点在输入框。点击面板外部、按 Esc、再按一次快捷键、再点一次图标，都会收起面板。收起时草稿保留，搜索状态重置。

## 4. 快速输入

| 按键 | 便签模式 | 待办模式 |
|---|---|---|
| ↩ | 提交 | 提交 |
| ⇧↩ | 换行 | 无作用 |
| Tab | 切换到待办模式 | 切换到便签模式 |
| ⌘1 / ⌘2 | 切到便签 / 待办 | 同左 |
| Esc | 收起面板（草稿保留） | 同左 |
| 输入法组合中（拼音未上屏）按 ↩ | 交给输入法处理，不提交 | 同左 |

- **占位文字：**便签模式「记点什么…（⇧↩ 换行）」；待办模式「要做什么？比如：周五下午三点交报告」。
- **高度：**从单行开始随内容增高；便签最多 6 行，待办最多 2 行，超出后在框内滚动。
- **连续记录：**提交后输入框清空、焦点保留；新条目出现在列表顶部，并短暂高亮 1 秒。
- **草稿：**两种模式各有一份草稿。收起面板、切换模式时都保留；退出拾刻时保存，下次启动恢复。
- **呼出即打字：**按下快捷键后立即打字，面板出现之前敲的字也要进入输入框，一个不丢（S1-04）。
- **提交失败：**输入内容保留不清空，顶栏下方出现红色提示条"保存失败：原因"和"重试"按钮。
- **时间识别提示（S2-01，仅待办模式）：**
  - 识别到的文字在输入框里用强调色显示。
  - 输入框下方一行小字，例如：`🕒 周五 15:00 提醒  ✕`。
  - 只有日期时显示"周六（全天）"；时间已过时用红色显示"今天 09:00（已过）"；相对时长显示为"今天 12:30 提醒（30 分钟后）"。
  - 点 ✕ 后提示变为灰色"不识别时间"，直到输入框被清空。

## 5. 便签

- **分组：**「置顶」（有置顶便签时才显示）和「便签」两组。置顶组按置顶时间排序，便签组按最近修改排序。
- **列表行：**显示内容前 3 行，超出部分省略；下方小字显示修改时间（刚刚 / 5 分钟前 / 今天 14:20 / 昨天 / 9月20日）。已钉到桌面的便签在行尾显示图钉图标（S3-01）。
- **编辑（S1-05）：**单击行即在原位变为编辑框。停止输入 0.5 秒后、失去焦点时、收起面板时自动保存。按 Esc 或点击别处结束编辑。编辑中 ⌘Z 撤销文字改动。结束编辑时内容为空，则视为删除（可撤销）。
- **悬停：**行尾出现 ⋯ 按钮，点击后打开与右键相同的菜单。
- **右键菜单：**编辑、置顶 / 取消置顶、复制内容、钉到桌面 / 取消钉住（S3-01）、转为待办（S5-03）、删除。

## 6. 待办与时间

- **列表行：**`○ 标题 · 时间`。已完成的显示为实心勾，标题划线并变灰。
- **时间显示：**今天 15:00 / 明天 / 周五 15:00 / 9月30日 / 2027年3月5日 15:00（今年以内不显示年份，全天待办不显示时刻）。逾期的时间显示为红色。
- **分组：**
  - 阶段 1：「待办」「已完成（N）」。
  - 阶段 2 起：「逾期」「今天」「以后」「无日期」「已完成（N）」（S2-06）。
  - 空的分组不显示；"已完成"默认折叠。
- **勾选完成：**立即划线变灰，1 秒后移入"已完成"组；这 1 秒内再点可以取消。
- **编辑标题：**单击标题原位编辑（单行）。编辑标题时不重新识别时间，时间通过"设置时间…"修改。
- **右键菜单：**编辑、设置时间…（S2-07）、转为便签（S5-03）、删除。
- **设置时间弹层（S2-07）：**日历选择日期，"包含时刻"开关，时刻选择；快捷按钮：今天、明天、下周一、清除时间。

## 7. 删除与撤销

- **删除入口：**右键"删除"；选中条目后按 ⌘⌫（S5-02）；编辑时把内容清空后结束编辑。
- **无需确认：**删除后，面板底部出现提示条"已删除「前 12 个字…」 撤销"，停留 5 秒。连续删除时提示条显示最近一条。
- **⌘Z：**在面板中（非编辑状态）按删除的先后顺序逐条撤销。
- **卡片联动：**删除已钉到桌面的便签时，卡片同时关闭；撤销后卡片恢复。
- **最近删除（S4-05）：**在设置 → 数据中打开。按删除时间排列，每条可以"恢复"或"永久删除"，也可以一键清空；超过保留期自动清除。

## 8. 搜索

（S2-09）

- **打开：**⌘F 或点顶栏的搜索按钮。搜索框替换快速输入框的位置，列表显示搜索结果。
- **范围：**所有未删除的便签内容和待办标题（包括已完成的）；不区分大小写；停止输入 0.2 秒后自动搜索。
- **结果：**分「便签」「待办」两组，匹配文字高亮。点击结果会退出搜索，切到对应模式，滚动到该条并高亮。
- **无结果：**显示"没有找到"××""。
- **关闭：**按 Esc 退出搜索，回到原来的模式。

## 10. 桌面卡片

（S3-01 至 S3-09）

### 10.1 结构

- **内容区：**便签全文，按所选字号显示，超出时可滚动。
- **顶部工具栏：**常驻显示、始终可点（ADR-026：功能不依赖悬停出现）；悬停时按钮从半亮提为全亮。左侧是拖动区域；右侧依次是编辑（铅笔 / ✓）、颜色（色板）、层级、⋯（卡片菜单）、✕（取消钉住）。
- **外观：**背景为所选颜色（浅色、深色模式各一套色值，见 §15），圆角 10 pt，带阴影。正文永远从工具栏下方开始，任何状态都不会被工具栏遮挡。

### 10.2 操作

- **钉出：**便签右键"钉到桌面"。新卡片默认大小 240×180 pt，出现在面板所在屏幕的中央偏上；和已有卡片重叠时依次错开 24 pt。
- **移动：**拖动顶部操作条。
- **调整大小：**拖右下角把手，最小 160×100 pt。
- **编辑：**点工具栏铅笔或双击内容区进入编辑；点 ✓、点击卡片外部或按 Esc 结束编辑；停止输入 0.5 秒后自动保存。卡片和面板中的同一便签实时同步。
- **不抢焦点：**不是编辑状态时，点击卡片不会让拾刻变成前台应用，当前正在用的应用保持活动。
- **取消钉住：**点 ✕、菜单中"取消钉住"或在卡片上按 ⌘W。只关闭卡片，便签本身保留。

### 10.3 显示层级

（S3-02，ADR-026 后经工具栏层级菜单选择，图标随当前层级变化）每张卡片单独选择。

| 层级 | 表现 |
|---|---|
| 浮在最上层（默认） | 始终在所有普通窗口之上；可选跟随所有空间 |
| 普通窗口 | 实际处于其他 app 普通窗口之下一档（ADR-031：保证永远不遮挡别的应用），点击后在本档内浮到前面；**固定只在钉出它的空间显示**（ADR-030） |
| 贴在桌面层 | 在所有窗口之下、壁纸之上（桌面图标层之上 1 档，ADR-026）；露出桌面时卡片可直接点击 |

### 10.4 自动隐藏

（S3-03）每张卡片可单独开关，默认关闭。

```
显示中 ──鼠标离开卡片满 N 秒──▶ 淡出（0.3 秒）──▶ 隐藏中
  ▲                                                │
  └──── 淡入（0.15 秒）◀── 鼠标在卡片区域停留 0.2 秒 ◀┘
```

- **N：**1 / 3（默认）/ 5 / 10 秒。
- **隐藏中的不透明度：**0%～60%，默认 20%；设为 0% 即完全看不见。
- **点击穿透：**隐藏中点击卡片所在位置，点到的是下面的窗口，卡片不挡任何操作。
- **不会隐藏的情况：**正在编辑、菜单打开、正在拖动或调整大小。

### 10.5 卡片菜单

（S3-08；ADR-026 后编辑 / 颜色 / 层级上移到工具栏顶层按钮，"编辑"在编辑中变为"✓"）

```
字号            ▸ 小 / 中 / 大
自动隐藏        ▸ 开启 ✓ / 延迟 ▸ / 隐藏后不透明度 ▸
空间            ▸ 所有空间 / 仅当前空间 / 显示在全屏应用之上 ✓
────────────
在面板中显示
取消钉住                    ⌘W
```

### 10.6 全部隐藏

（S3-09）右键菜单中的"隐藏所有卡片"会临时隐藏全部卡片，但不改变任何卡片的设置；"显示所有卡片"恢复显示。重启拾刻后卡片恢复显示。

## 11. 提醒通知

（S2-04、S2-10）

- **内容：**标题为待办标题；正文为时间，如"今天 15:00"或"全天 · 今天"；声音为系统默认提示音。
- **按钮：**"完成""稍后提醒（10 分钟）"，括号中的时长随设置变化。
- **点击通知本体：**打开面板，切到待办模式，滚动到该条并高亮 1.5 秒。
- **拾刻在前台时：**同样显示通知横幅。
- **权限：**第一次创建带时间的待办时请求通知权限；被拒绝后的表现见 §14。

## 12. 首次启动引导

（S4-08）一个小窗口，共 3 步，随时可以跳过：

1. 拾刻住在菜单栏（箭头指向图标）；快捷键 ⌥N 随时呼出，可在设置中修改。
2. 便签和待办：按 Tab 在两种模式之间切换。
3. 试一试：在待办模式输入"明天上午十点开会"，看时间被识别出来；随后请求通知权限。

## 15. 视觉与文案

## 16. 主窗口

（阶段 3.5，S3.5-01～06；产品分工见 ADR-023：面板承载全部现有能力，主窗口只做面板物理上做不了的增量）

### 16.1 骨架

- **打开：**菜单栏图标右键菜单"打开主窗口"；设置-通用页"打开主窗口"按钮。已有窗口时前置聚焦，不重复开窗。
- **窗口：**可调整大小，尺寸与位置记住（下次打开恢复）；关闭窗口只是关窗，拾刻继续驻留菜单栏。
- **布局：**左侧栏（三入口）+ 右侧内容区；左栏宽约 180pt。

### 16.2 左栏三入口

- 便签 / 待办 / 回收站；选中态记忆（重启后回到上次的入口）。
- 不做项目/标签系统（阶段 1 边界延续）。

### 16.3 便签视图（S3.5-03）

- 全部便签，置顶分组在前列；搜索框按内容即时过滤。
- 单击即原位编辑；失焦/Esc 结束，防抖自动保存，与面板同语义（清空=删除入撤销栈）。
- 右键菜单与面板便签行一致（置顶/取消置顶、钉到桌面/取消钉住、删除）。

### 16.4 待办视图（S3.5-04）

- 全部待办按分组：逾期 / 今天 / 以后 / 无日期 / 已完成；搜索框过滤。
- 勾选完成 / 勾回；带时间的待办完成即取消通知（与面板同语义）。
- 右键菜单与面板待办行一致。

### 16.5 回收站（S3.5-05）

- 已删除的便签与待办分两组列出，显示原内容与删除时间。
- 恢复：回到删除前状态（待办回面板对应分组）。
- 永久删除：单条与清空均需确认；不可恢复，反馈条如实提示。

### 16.6 导出（S3.5-06）

- 导出为 Markdown / JSON（便签+待办全量）；系统保存面板选位置；成功后反馈条显示路径。

### 16.7 与面板的一致性

- 两侧同时打开，增删改即时互见（同一仓储观察流，无手动刷新）。
- 同一条内容两侧同时编辑无锁：后保存者覆盖（与面板现状同假设，单人单机）。

### 16.8 反馈与撤销（打磨二轮补记，2026-10-02）

- **删除反馈与撤销：**主窗口发起的删除（行删除按钮 / 右键删除 / 清空内容保存）在底部反馈条显示"已删除「…」"，条尾带「撤销」按钮——**定点恢复该条所指条目**（卡C 审查修复，2026-10-02：5 秒窗口内另一面又删了别的条目时，栈顶已不是文案所指；且不被面板编辑态/输入焦点守卫吞掉——那两个守卫是 ⌘Z 键路径仲裁，条上按钮是显式点击），显示窗口 5 秒与面板撤销条一致。面板收着时主窗口不再对删除无感。面板自身撤销条的按钮同走守卫外定点路径（展示的恒为栈顶）；⌘Z 仍为栈顶逐条撤销并保留编辑态/焦点仲裁，语义不变。若所指条目已被 ⌘Z 先行恢复，撤销按钮静默收条（不重复恢复、不报 notFound）。
- **撤销不可达的删除：**回收站的恢复/永久删除/清空不提供撤销（永久删除语义如此）。
- **写失败重试：**写失败旁路（§16.7 之上，W3）的反馈条条尾带「重试」，复用面板横幅的同一重试闭包——面板收着时不必先呼出面板才能重试。
- 其余反馈（导出成败、读失败、回收站写失败）为纯文案，3 秒自清不带按钮（读失败的「重试」出口在各分区失败空态，照旧）。
