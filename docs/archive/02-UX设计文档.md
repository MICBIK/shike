# TZMemo UX 设计文档

> 文档编号：02 ｜ 状态：评审中（M2+ 章节为提案，确认后生效）｜ 上次更新：2026-09-23
> M1 冒烟界面为临时调试形态，不按本文档验收；本文档自 M2 起生效。

## 1. 信息架构

```
TZMemo（菜单栏应用，无 Dock 图标）
├── 菜单栏图标（状态：图标 / 未完成计数）
│   └── 弹出面板（主界面，transient）
│       ├── 顶栏：模式切换（便签｜待办）、搜索入口、设置入口
│       ├── 快速输入区（焦点默认在此）
│       └── 内容列表（按当前模式显示便签或待办）
├── 悬浮便签卡片（NSPanel，可多实例，钉出/收回）
└── 设置窗口（独立，非 transient）
    ├── 通用（自启、深浅色、透明度、排序）
    ├── 快捷键（呼出/收起、新建）
    ├── 提醒（默认提前量、通知权限状态）
    └── 关于（版本、检查更新、GitHub 链接）
```

## 2. 核心流程

**捕捉流（灵魂流程，验收标准 ≤3 秒）：**
```
快捷键/点击图标 → 面板弹出+焦点在输入框 → 打字
  → [待办模式] 输入中实时解析 → 命中日期在输入框内原位高亮
  → Enter 提交 → 列表新增 + 输入框清空且焦点保持 → 可连续记录
  → 点击外部/Esc → 面板收起
```

**提醒流：** 待办携带 remindAt → 到点前（默认准点）系统通知 → 点通知唤起面板并定位该待办。

**钉便签流：** 便签行右键/按钮「钉到桌面」→ NSPanel 卡片出现（复用便签内容）→ 拖动定位 → 面板内该便签显示"已钉"标记 → 卡片上关闭 = 取消钉住（不删数据）。

## 3. 界面要素规格

### 3.1 弹出面板（M2）

| 要素 | 规格 |
|---|---|
| 尺寸 | 默认 380×520pt；右下角拖拽把手可调；尺寸持久记忆（UserDefaults） |
| 背景 | 毛玻璃材质（NSVisualEffectView / HUDWindow 风格），可关 |
| 顶栏 | 左：模式切换（Segmented）；右：搜索按钮、设置齿轮 |
| 输入区 | 单行输入框，placeholder 随模式切换（「记录点什么…」/「如：周五下午三点交报告」） |
| 列表 | 分组：置顶 / 未完成待办 / 已完成（折叠）；右键菜单：编辑、置顶、钉出、删除 |
| 空状态 | 图标 + 一句话引导（参考 demo EmptyStates） |

### 3.2 悬浮便签卡片（M3）

| 要素 | 规格 |
|---|---|
| 窗口 | NSPanel：非激活样式（.nonactivatingPanel）、浮动层级、圆角、阴影 |
| 内容 | 便签全文（可滚动），底部：编辑、换色（P2）、取消钉住 |
| 行为 | 标题栏区域拖动；不抢焦点；重启后位置记忆（P1） |

### 3.3 菜单栏图标

两种模式（设置切换）：① 纯图标（SF Symbol）；② 图标+未完成待办计数。

## 4. 交互规范

- **键盘**：Enter 提交；Esc 收起面板；⌘F 聚焦搜索；↑↓ 列表导航；⌘⌫ 删除选中项（需可撤销）。
- **完成动画**：待办勾选时划线 + 缩放消隐至"已完成"组（参考 demo completion animation）。
- **解析高亮**：命中文本在输入框内着色（日期蓝/标签色），格式对齐 demo 的 RmbHighlightedTextField 思路（自研实现，不抄代码）。
- **防误删**：删除走确认或 Toast 撤销（⚠️ 待确认，见 PRD 开放项 1）。
- **通知权限**：首次创建带提醒待办时请求；被拒后面板内显示降级提示条。

## 5. 状态设计

| 状态 | 表现 |
|---|---|
| 空列表 | ContentUnavailableView + 引导文案 |
| 搜索无结果 | 「没有找到“××”」+ 清除搜索按钮 |
| 通知权限被拒 | 面板顶部提示条 + 跳系统设置按钮 |
| 数据库异常 | 内存库兜底 + 顶部错误提示条（数据仅本次会话） |

## 6. 视觉

- 深浅色跟随系统；语义色用系统调色板；主色待定（提案：系统蓝，评审项）。
- 中文字体：系统默认（PingFang SC），正文 13pt，列表行高 ≥28pt 保证可点。
