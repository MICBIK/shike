## 协作流程（确认制，ADR-009）

```
迭代开工：AI 更新「07-迭代计划」任务表 + 涉及的 02/03 设计章节
    → 产品负责人确认  →  实现（代码+L1/L2 测试）  →  产品负责人按验收清单实测
    → 回顾表沉淀  →  Backlog 状态同步
```

## 文档维护规则

- **改代码必改文档**：新增用户故事 → 01；新界面/交互 → 02；模块/表结构变更 → 03；依赖或方案变更 → 05 新增 ADR。
- **ADR 只增不改**：推翻旧决策时新增条目并链接旧条目。
- **07-迭代计划**是活文档：任务表状态、验收结论、回顾随迭代滚动更新。
- **06-Backlog**是唯一的需求池：任何新想法先进 Backlog，再进迭代。
