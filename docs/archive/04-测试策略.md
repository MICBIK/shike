# TZMemo 测试策略

> 文档编号：04 ｜ 状态：生效中 ｜ 上次更新：2026-09-23

## 1. 测试分层

| 层 | 载体 | 运行环境 | 覆盖对象 |
|---|---|---|---|
| 解析回归（L1） | `swift run parser-check`（可执行测试器，144 断言） | CLT 即可，无需 Xcode，可入 CI | ChineseDateParser 全部规则 |
| 单元测试（L2） | XCTest（Tests/TZMemoTests） | 需 Xcode（Cmd+U） | MemoStore CRUD、AppDatabase 迁移、软删行为 |
| 手动验收（L3） | 各迭代验收清单（07-迭代计划） | 用户实测 | 交互、动画、系统集成（通知/自启/更新） |

原则：**越靠下的层越多**。解析规则是纯逻辑，全部在 L1 钉死；Store 层逻辑 L2 覆盖；只有真正需要人眼的（视觉/系统行为）留给 L3。

## 2. 覆盖要求（Definition of Done 的一部分）

- 新增/修改解析规则 → 必须同步新增 L1 断言（含边界与反例）；
- MemoStore 新增操作 → L2 单测（内存库）；
- 修 Bug → 先写复现断言再修（L1 或 L2）。

## 3. 发版前回归清单（0.5 / 1.0 前逐项打勾）

- [ ] `swift run parser-check` 全绿
- [ ] `Cmd+U` 单元测试全绿
- [ ] 手动走查：捕捉流 ≤3 秒（快捷键呼出→输入→回车）
- [ ] 深浅色切换无破相
- [ ] 杀进程重启，数据完整
- [ ] 通知权限拒绝路径可用（降级提示）
- [ ] 全新机器安装路径（GitHub 下载 → 右键打开）可走通

## 4. 已知测试环境限制

- 本机曾仅有 CLT（无 XCTest）：L2 需 Xcode；L1 设计为 CLT 可跑，保证任何时候都能回归解析器。
- XCTest 宿主配置：TZMemoTests 以 TZMemo.app 为 TEST_HOST（project.yml 已配置）。
