## 1. 架构分层

```
┌─ Presentation ────────────────────────────────┐
│ SwiftUI Views（面板/列表/设置） + AppKit 桥接    │
│ （M2: StatusItemController + Popover；M3: StickyPanelWindow）│
├─ Application ─────────────────────────────────┐
│ MemoStore（数据入口/Repository 角色）            │
│ ReminderScheduler（M4，UNUserNotificationCenter）│
│ UserPreferences（设置，UserDefaults 单一来源）    │
├─ Domain ──────────────────────────────────────┤
│ Note / Todo（实体）；ChineseDateParser（独立包）  │
├─ Infrastructure ──────────────────────────────┤
│ AppDatabase（GRDB/SQLite）；Sparkle（M5）；      │
│ LaunchAtLogin（SMAppService）                   │
└───────────────────────────────────────────────┘
依赖规则：上层依赖下层；ChineseDateParser 零依赖；UI 不直接触碰 AppDatabase。
```

## 3. 数据模型（v1 迁移已建表 ✅）

**note**: id（自增）｜uuid（同步键）｜content｜color?｜pinned｜createdAt｜updatedAt｜deleted（软删）
**todo**: id｜uuid｜title｜detail?｜done｜doneAt?｜dueAt?｜remindAt?｜priority?｜repeatRule?｜listTag?｜pinned｜createdAt｜updatedAt｜deleted

同步预埋约定：所有业务写操作必须刷新 `updatedAt`；删除一律软删；uuid 为未来跨设备主键。

## 4. M2 关键技术方案（提案，待确认）

- **NSStatusItem + NSPopover**（demo 同款架构，见 ADR-001 理由）：
  - `popover.behavior = .transient`；`animates` 与否对齐 demo（false）；
  - 面板尺寸用户可拖拽并持久记忆（含右下角把手，demo PopoverResizeHandleView 思路自研）；
  - 点击面板外收起由 transient 行为覆盖，焦点回归用 popover 生命周期事件管理。
- **全局快捷键**：KeyboardShortcuts（Sindre Sorhus，MIT）或 Carbon RegisterEventHotKey 自封装，二选一在实现时定。
- **LSUIElement**：deployment 时 YES（开发期保持 NO 便于调试）。
- **UserPreferences**：单一 ObservableObject + 集中键名枚举（demo 模式）。

## 5. M3 关键技术方案（提案）

- 悬浮卡片 = `NSPanel(styleMask: [.borderless, .nonactivatingPanel])`，`level = .floating`；
- `StickyPanelController` 管理多实例生命周期（uuid ↔ 窗口映射）；
- 拖动：panel `isMovableByWindowBackground = true`；不抢焦点由 nonactivatingPanel 保证。

## 6. 中文日期解析引擎（已实现 ✅）

- 独立包 `TZMemoDateParser`，纯函数 + 规则驱动；`parse(text, now) -> DateParseResult?`（date、matchedRanges 高亮区间、hasExplicitTime、containsTimeOfDayHint）。
- v1 规则范围：相对日（今天/明天/后天/大后天）、X天(之/以)后、周X（下周X/下下周X/这周X，星期/礼拜变体）、X月X号（今年已过滚明年，支持年份数字）、下个月X号、时段+时刻组合（明早八点/周五下午三点/晚上十二点=次日零点）、裸时刻口语推断（1~6 点视为下午）、仅时刻已过顺延明天、周X已过顺延下周。
- 关键实现：时刻匹配前把日期命中区**遮蔽为等长占位符**，杜绝「周五三点」→「五三点」的贪婪跨界。
- 明确不做（v1）：农历、节日语义、模糊语（月底）。规则表 + 断言（144 条）= 未来 Dart 版移植规格。

## 7. M4 提醒方案（提案）

- `UNUserNotificationCenter`：待办保存时注册/更新对应 notification（identifier = todo.uuid）；
- 完成/删除/编辑同步撤销或重排通知；权限被拒 → UI 降级提示（UX §5）。

## 8. 错误处理与并发

- DB 打开失败 → 内存库兜底 + UI 错误条（数据仅本会话，明确告知）；
- 并发模型：UI 与 MemoStore 全部 `@MainActor`；GRDB DatabaseQueue 串行写；解析器纯函数无共享状态；
- Swift 6 strict concurrency：全局可变状态禁止（教训：回归测试器曾因此返工为 @main 结构）。

## 9. 性能预算

| 指标 | 预算 | 手段 |
|---|---|---|
| 面板呼出 | <300ms | StatusItem 常驻 + popover 预热，不做懒加载 |
| 常驻内存 | <80MB | 原生栈（ADR-001 的核心收益） |
| 列表滚动 | 1000 条不卡 | List 懒加载；软删数据不进查询 |
