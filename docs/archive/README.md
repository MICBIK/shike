# 归档：TZMemo 旧文档

这里保存项目改名为拾刻之前（项目名 TZMemo）的全部文档，内容保持 2026-09-24 的原样，不再更新。原来的文档索引改名为 `旧文档索引.md`，其中"本目录是唯一事实来源"的说法已不再成立，现行文档见 [docs/README.md](../README.md)。

- **最初的想法：**`需求梳理.md` 记录了产品负责人最初的想法（v1 → v3.1），想了解需求从哪里来，可以从它读起。
- **取代关系：**每条新决策和旧决策的关系，见 [07-决策记录](../07-决策记录.md) 中各条的"关联"。

阅读时请注意，以下内容已被证实不准确或已经过时：

| 最低系统 macOS 13 | 已改为 macOS 15，见 ADR-003 |
| 规划 iOS、Windows、Android 和同步 | 已移入"以后再说"，见 ADR-002 |
