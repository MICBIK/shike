# 01 · 产品定义

> 状态：生效中 ｜ 更新：2026-09-25 ｜ 负责人：产品负责人（MICBIK）

## 1. 一句话

**拾刻是一款 macOS 菜单栏便签与待办应用：随手呼出，几秒记下；便签能钉在桌面上随时看，待办能用中文说时间、到点提醒。**

## 2. 名字

「拾刻」（Shike）：**拾**是随手拾起，**刻**是时刻，整个词读音同「时刻」。拾起的是一闪而过的念头，时刻对应的是到点提醒。

## 3. 用户与场景

| 用户 | 典型场景 | 拾刻要做到的 |
|---|---|---|
| 在电脑前工作的人（首要用户） | 开会、写代码时突然冒出一个想法或待办，不想离开当前窗口 | 快捷键呼出 → 打字 → 回车，全程 3 秒以内 |
| 有一堆琐事、需要被提醒的人 | "周五下午三点交报告"，希望说一句话就把时间也定好 | 输入框识别中文时间，提交即建提醒，到点弹通知 |
| 希望重要信息一直看得见的人 | 把电话号码、会议要点贴在屏幕上，又不想它挡住视线 | 便签钉成桌面卡片，可置顶、可自动隐藏、鼠标靠近再浮现 |

便签和待办**同等重要**，两者都是高频用法。

## 4. 产品原则

发生取舍时按以下顺序判断：

1. **不丢数据。**宁可明确报错，也不能静默丢失用户记下的任何内容。
2. **捕捉优先。**任何设计都不能让"记下来"这件事变慢。
3. **让用户选。**一个行为有多种合理形式时，做成选项并给出合理的默认值，而不是写死一种。
4. **中文优先。**中文输入法、中文时间说法是一等公民。
5. **本地、私密。**数据只存在本机，没有账号、没有遥测。
6. **轻。**常驻内存小，呼出快，不打扰。

## 5. 范围

### 5.1 1.0 包含的能力

| 领域 | 能力 |
|---|---|
| 捕捉 | 菜单栏常驻、全局快捷键呼出、便签/待办两种模式、中文输入法安全、呼出后立即打字不丢字 |
| 便签 | 新建、多行、编辑、置顶、删除与撤销、搜索 |
| 待办与提醒 | 新建、完成、编辑、删除与撤销、中文时间识别与高亮、到点通知（可完成、可稍后提醒）、按逾期/今天/以后分组、菜单栏计数 |
| 桌面卡片 | 便签钉到桌面、多张卡片、层级/自动隐藏/透明度/点击穿透/颜色/大小/空间等全部可选、卡片上直接编辑 |
| 数据安全 | 写入失败不丢内容、每日自动备份、最近删除可恢复、导出 Markdown/JSON |
| 系统与分发 | 设置窗口、开机自启、GitHub 下载安装、Sparkle 自动更新、首次启动引导 |

各能力在哪个阶段交付，见 [02-阶段路线图](02-阶段路线图.md)。

### 5.2 1.0 明确不做

账号、云同步、iOS / Windows / Android 版本、富文本与 Markdown 渲染、协作分享、重复待办、优先级、标签与分组、App Store 上架。

### 5.3 以后再说

以下事项不作为现在的设计约束，有明确触发条件时再立项：

| 事项 | 触发条件 |
|---|---|
| 加入 Apple 开发者计划（签名、公证，安装不再被系统拦截） | 1.0 发布后反响不错 |
| iOS 版本 | 看 Mac 版的使用情况再决定 |
| 云同步与账号 | 有了第二个平台之后 |
| 重复待办、优先级、标签 | 自用或朋友反馈中反复出现 |

## 6. 平台与分发

- **系统要求：**macOS 15 或更高（Apple 芯片；Intel Mac 可用到 macOS 26）。
- **分发：**GitHub Releases 免费下载，Sparkle 自动更新。
- **协议：**GPL-3.0 开源，源码在 <https://github.com/MICBIK/shike>。
- **语言：**简体中文界面。

## 7. 成功指标（1.0）

| 目标 | 衡量方式 |
|---|---|
| 捕捉够快 | 从按下快捷键到记录完成 ≤ 3 秒（手动计时） |
| 自己离不开 | 产品负责人连续自用 ≥ 30 天 |
| 朋友愿意用 | ≥ 10 人安装，≥ 5 人每周使用（通过 GitHub Issues、微信收集反馈） |
| 质量底线 | 没有数据丢失类问题；中文时间解析用例全部通过 |

## 8. 约束

- 一名产品负责人加 AI 助手开发。
- 暂不加入付费开发者计划，因此安装时需要用户手动放行一次（见 [07-决策记录](07-决策记录.md) ADR-011）。
- 项目以 GPL-3.0 发布，任何发行版本都必须同时提供源码。
