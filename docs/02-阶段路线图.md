# 02 · 阶段路线图

> 状态：生效中 ｜ 更新：2026-09-25
> 本文件是"做什么、什么时候做完、怎样算做完"的唯一来源。能力编号（如 S1-04）在交互设计、技术架构以及 BMAD 的阶段规格和故事中引用。

## 总览

| 阶段 | 版本 | 主题 | 面向 | 状态 |
|---|---|---|---|---|
| 0 | v0.0 | 地基：完整项目框架 | 开发 | 进行中 |
| 1 | v0.1 | 随手记 | 自用 | 未开始 |
| 2 | v0.2 | 到点提醒 | 自用 | 未开始 |
| 3 | v0.3 | 钉在桌面 | 自用 | 未开始 |
| 4 | v0.5 | 朋友内测 | 朋友 | 未开始 |
| 5 | v1.0 | 正式版 | 公开 | 未开始 |

状态取值：未开始 / 进行中 / 待验收 / 已完成。阶段 2 和阶段 3 互不依赖，必要时可以对调顺序。

## 阶段规则

1. **先计划后动手。**每个阶段开工前，用 BMAD 生成该阶段的规格和故事（流程见 [06 §8](06-开发规范.md#8-阶段工作流程)），产品负责人确认后再开始写代码。
2. **阶段内不加范围。**新想法记到 GitHub Issues（标签 `idea`），阶段结束时再评估放进哪个阶段。
3. **验收由产品负责人执行。**对照本文件的验收清单逐条实测，全部通过后合并到 main 分支并打版本标签。
4. **完成以事实为准。**"完成"指 CI 通过加上实测通过，而不是文档里写了"完成"（见 [06-开发规范](06-开发规范.md) §7）。

## 阶段 0 · 地基（v0.0）

**目标：**一个干净的、能编译、有测试、有 CI 的工程。所有模块都已搭好并接通，功能留到后续阶段。这就是"完整项目框架"。

| 编号 | 能力 | 说明 |
|---|---|---|
| S0-01 | 仓库基础 | GPL-3.0 许可证、NOTICE（致谢与第三方声明）、README、.gitignore、目录结构 |
| S0-02 | 工程与分层 | XcodeGen 生成工程；App 目标 `Shike`（macOS 15、Swift 6、无 Dock 图标）；本地 Swift 包 `ShikeKit`（`ShikeDateParser`、`ShikeData`） |
| S0-03 | 解析引擎迁移与修复 | 从旧项目迁入并改名；修复已知时段错误；补齐冒号时间、相对时长、下周、周末等说法；加入"X点"歧义规则；固定公历、周一为一周之首。[05 用例表](05-中文日期解析规格.md#9-用例表)的每一行都有对应测试 |
| S0-04 | 数据层 v1 | 便签、待办、桌面卡片三张表；数据读写接口；数据变化自动通知界面；软删除 |
| S0-05 | 数据安全底座 | 保存失败时向界面报告错误（不吞错误）；数据库打不开时弹出明确提示（重试 / 打开数据目录 / 退出）；每日自动备份，保留最近 7 份 |
| S0-06 | 运行外壳 | 菜单栏图标；左键弹出面板（含模式切换和空状态）；右键菜单（设置…、关于拾刻、退出拾刻）；设置窗口骨架（各分页占位）；关于页显示版本、许可证与源码链接 |
| S0-07 | CI | GitHub Actions：推送与 PR 时运行包测试并构建 App |

**验收清单**

- [ ] GitHub 上 main 分支的 CI 显示通过。
- [ ] 终端运行 `swift test --package-path Packages/ShikeKit` 全部通过。
- [ ] 执行 `xcodegen generate` 后在 Xcode 中运行：菜单栏出现拾刻图标，Dock 中没有图标。
- [ ] 左键点击图标弹出面板，能看到「便签｜待办」模式切换和空状态提示；点击面板外部，面板收起。
- [ ] 右键点击图标出现菜单；"设置…"打开设置窗口并显示在最前面；"退出拾刻"能退出。
- [ ] 用调试启动参数模拟数据库打不开：弹出提示，提供"重试""打开数据目录""退出"三个按钮。
- [ ] 运行一次后，数据目录下的 `Backups` 文件夹中有当天的备份。

## 阶段 1 · 随手记（v0.1）

**目标：**菜单栏里的便签和待办形成闭环，产品负责人开始每天使用。本阶段待办不带时间。

| 编号 | 能力 | 说明 |
|---|---|---|
| S1-01 | 面板行为 | 左键开关面板；点击外部收起（含兜底机制）；Esc 收起；拖动右下角调整大小并记住尺寸（不超出屏幕）；不出现"刚关上又弹开" |
| S1-02 | 全局快捷键 | 默认开启，默认组合 ⌃⌥N（本阶段实测无冲突后定稿）；再按一次收起；可在设置中修改或关闭 |
| S1-03 | 模式切换 | 「便签｜待办」分段控件；输入框内按 Tab 切换，⌘1 / ⌘2 直达；呼出时进入哪个模式可选：上次的模式（默认）/ 总是便签 / 总是待办 |
| S1-04 | 快速输入框 | 呼出即聚焦；呼出后立刻打字不丢字；↩ 提交；⇧↩ 换行（仅便签模式）；输入法组合中按 ↩ 只上屏不提交；提交后清空并保持焦点，可连续记录；空内容提交无反应；面板收起时未提交内容作为草稿保留（两种模式各自保留）；输入框随内容增高，便签最多 6 行后滚动 |
| S1-05 | 便签列表与编辑 | 置顶的在前（按置顶时间），其余按最近修改；每行显示前 3 行和修改时间；单击原位编辑，自动保存（停止输入 0.5 秒后、失去焦点、收起面板时）；右键菜单：编辑、置顶/取消置顶、复制内容、删除 |
| S1-06 | 待办列表与完成 | 未完成的在前，新建的在上；勾选后划线变灰，1 秒后移入折叠的"已完成"组，可再勾回；单击标题原位编辑；右键菜单：编辑、删除 |
| S1-07 | 删除与撤销 | 删除无需确认；面板底部显示"已删除「…」 撤销"5 秒；面板内 ⌘Z 撤销最近一次删除 |
| S1-08 | 开机自启 | 在右键菜单和设置-通用中开关；状态以系统为准；需要在系统设置中批准时给出指引 |
| S1-09 | 右键菜单完整 | 打开拾刻、设置…、开机自启（勾选项）、关于拾刻、退出拾刻 |
| S1-10 | 空状态 | 便签模式、待办模式各自的空状态引导文案 |

**验收清单**

- [ ] 计时：按快捷键 → 输入"测试一下" → 回车，3 秒内完成，列表立即出现该条。
- [ ] 用拼音输入法打字，拼音还没上屏时按回车：只完成上屏，不提交；再按一次回车才提交。
- [ ] 按下快捷键后不等面板出现就连续打字，打出的字一个不丢。
- [ ] 便签模式下 ⇧↩ 能换行；多行便签在列表中显示前 3 行。
- [ ] 输入一半按 Esc 收起面板，再次呼出时草稿还在。
- [ ] 删除一条便签后点"撤销"或按 ⌘Z，便签恢复，内容和位置不变。
- [ ] 拖动调整面板大小，退出重开后尺寸保持。
- [ ] 打开开机自启，注销再登录后拾刻自动运行。
- [ ] 退出重开，所有便签、待办及完成状态都在。
- [ ] 连续自用一周，没有丢失任何内容。

## 阶段 2 · 到点提醒（v0.2）

**目标：**待办获得时间能力。"周五下午三点交报告"一句话从记录到提醒走完全程。

| 编号 | 能力 | 说明 |
|---|---|---|
| S2-01 | 时间识别与高亮 | 待办模式下边输入边识别（规则见 [05](05-中文日期解析规格.md)），识别到的文字高亮；输入框下方显示结果提示，如"周五 15:00 提醒""周六（全天）""今天 09:00（已过）"；提示上的 × 可取消本次识别，在输入框清空前不再识别。便签模式不识别 |
| S2-02 | 提交与标题清理 | 提交时按 [05 §7](05-中文日期解析规格.md#7-标题清理) 的规则，从标题中去掉识别到的时间文字，并清理首尾的空白、标点和"提醒我""记得"等词；清理后为空则保留原文 |
| S2-03 | 待办时间规则 | 有具体时刻的待办在该时刻提醒；只有日期的全天待办在"全天待办提醒时间"提醒（默认 09:00，可设置）；已经过去的时间照常保存为逾期，不发通知 |
| S2-04 | 到点通知 | 系统通知显示待办标题和时间；带"完成""稍后提醒"按钮（稍后时长可设：5 / 10（默认）/ 15 / 30 / 60 分钟）；点击通知打开面板、切到待办模式并定位到该条；拾刻没在运行时通知照常送达 |
| S2-05 | 通知调度 | 以数据库为准核对系统中已排的通知（启动、数据变化、跨天、唤醒时）；只排最近的 50 条 |
| S2-06 | 待办分组 | 逾期（红色）/ 今天 / 以后 / 无日期 / 已完成（折叠）；组内按时间先后；跨天和唤醒后自动重新分组 |
| S2-07 | 编辑时间 | 右键"设置时间…"：选日期、选是否带时刻；快捷选项：今天、明天、下周一、清除时间 |
| S2-08 | 菜单栏计数 | 显示方式可选：不显示 / 逾期+今天（默认）/ 全部未完成；待办模式按钮上显示同样的数字角标 |
| S2-09 | 搜索 | ⌘F 或点放大镜打开搜索框；同时搜索便签内容和待办标题，结果分两组，匹配文字高亮；Esc 关闭搜索 |
| S2-10 | 通知权限 | 第一次创建带时间的待办时请求权限；被拒绝后，待办模式顶部显示提示条"通知已关闭，到点不会提醒"和"打开系统设置"按钮 |

**验收清单**

- [ ] 待办模式输入"周五下午三点交报告"：输入过程中"周五下午三点"高亮，下方提示"周五 15:00 提醒"；回车后列表显示"交报告 · 周五 15:00"。
- [ ] 建一条 2 分钟后的待办，到点收到通知；点"稍后提醒"，10 分钟后再次收到。
- [ ] 在通知上点"完成"，该待办变为已完成。
- [ ] 退出拾刻后到点仍收到通知；在通知上点"完成"，拾刻启动并完成该待办。
- [ ] 输入"有两点需要注意"不高亮；输入"两点开会"高亮；点提示上的 × 后不再识别。
- [ ] 在系统设置中关闭拾刻的通知，面板出现提示条，按钮能跳转到系统设置。
- [ ] 过了午夜，"今天"组中未完成的待办自动移到"逾期"。
- [ ] 菜单栏数字等于逾期加今天未完成的数量，完成一条后立即减少。
- [ ] 搜索"报告"能同时找到便签和待办中的内容。

## 阶段 3 · 钉在桌面（v0.3）

**目标：**便签可以钉成桌面卡片。卡片的每一种表现方式都由用户选择。

| 编号 | 能力 | 说明 |
|---|---|---|
| S3-00 | 技术验证 | 先验证"卡片隐藏且点击穿透时，靠全局鼠标监听唤回"，以及三种层级在多空间、全屏应用、多显示器下的表现，结论记入 [07](07-决策记录.md) |
| S3-01 | 钉出与收回 | 便签右键"钉到桌面"生成卡片；可钉多张；面板中已钉的便签显示图钉标记；卡片上"取消钉住"关闭卡片，便签本身保留；删除便签时卡片随之关闭，撤销删除后卡片恢复 |
| S3-02 | 显示层级 | 浮在最上层（默认）/ 普通窗口 / 贴在桌面层；每张卡片单独设置；设置中有新卡片的默认值 |
| S3-03 | 自动隐藏 | 可开关（默认关）；鼠标离开后多久开始淡出：1 / 3（默认）/ 5 / 10 秒；隐藏后的不透明度 0%～60%（默认 20%）；隐藏时点击穿透；鼠标移入卡片区域 0.2 秒后浮现；编辑中或菜单打开时不隐藏 |
| S3-04 | 外观 | 颜色预设：黄（默认）、绿、蓝、粉、紫、灰，深色模式自动适配；拖动边缘调整大小（有最小尺寸）；字号：小 / 中（默认）/ 大；圆角与阴影 |
| S3-05 | 空间与全屏 | 显示在所有桌面空间（默认）/ 仅在钉出时所在的空间；是否显示在全屏应用之上（默认否） |
| S3-06 | 卡片上编辑 | 双击进入编辑，自动保存；与面板中的同一便签实时同步 |
| S3-07 | 恢复与屏幕变化 | 位置、大小和各项设置持久保存，重启后恢复；显示器断开或分辨率变化后，卡片自动移回可见区域 |
| S3-08 | 卡片菜单 | 右键：编辑、颜色、层级、自动隐藏…、在面板中显示、取消钉住 |
| S3-09 | 全部显示/隐藏 | 菜单栏图标右键菜单中"隐藏所有卡片 / 显示所有卡片" |

**验收清单**

- [ ] 钉出 3 张卡片，分别设为三种层级：最上层的不被任何窗口遮挡；普通窗口的会被遮挡，点击后浮到前面；桌面层的在所有窗口之下。
- [ ] 开启自动隐藏：鼠标离开 3 秒后卡片淡到设定的不透明度；此时点击卡片所在位置，点到的是下面的窗口；鼠标移回卡片位置，卡片浮现并可操作。
- [ ] 不透明度设为 0%：卡片完全看不见，鼠标移过去能唤出。
- [ ] 在卡片上双击编辑，面板中的同一便签同步变化；反过来也一样。
- [ ] 切换桌面空间："所有空间"的卡片跟随显示，"仅所在空间"的留在原空间。
- [ ] 退出重开，所有卡片的位置、大小、颜色、层级、隐藏设置不变。
- [ ] 断开外接显示器，原来在外接屏上的卡片出现在主屏可见区域。
- [ ] 删除一张已钉的便签，卡片消失；撤销删除后卡片回来。

## 阶段 5 · 正式版（v1.0）

**目标：**打磨到可以公开推荐的程度，并达成 [01 §7](01-产品定义.md#7-成功指标10) 的成功指标。

| 编号 | 能力 | 说明 |
|---|---|---|
| S5-01 | 完成动画 | 勾选待办时的完成动画，可在设置中关闭 |
| S5-02 | 键盘操作 | ↑↓ 选择条目、↩ 编辑、空格完成或取消完成待办、⌘⌫ 删除、⌘P 把便签钉到桌面 |
| S5-03 | 便签与待办互转 | 右键"转为待办 / 转为便签"：便签转待办时全文合并为一行作为标题；待办转便签时标题成为内容，时间信息丢弃（转换前提示） |
| S5-04 | 外观设置 | 深浅色：跟随系统（默认）/ 浅色 / 深色；面板背景：系统材质（默认）/ 不透明；排序：便签按修改或创建时间，待办按时间或创建时间；时间格式：24 小时制（默认）/ 12 小时制 |
| S5-05 | 性能达标 | 冷启动 < 1 秒；呼出面板 < 300 毫秒；空闲内存 < 80 MB；便签和待办各 1000 条时滚动流畅；测量结果记录到 [04 §10](04-技术架构.md#10-性能预算) |
