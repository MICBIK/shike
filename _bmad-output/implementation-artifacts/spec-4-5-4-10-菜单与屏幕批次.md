## 4.5 外观 + 4.6 空间 + 4.9 卡片菜单（合并实现）

- ⋯ 菜单升级为 03 §10.5 全量：编辑（双击等价入口）/ 颜色▸（六色）/ 字号▸（三档）/ 层级▸（三档，与操作条循环按钮同源）/ 空间▸（所有空间/仅所在空间 + 显示在全屏应用之上 Toggle）/ 自动隐藏▸（S3-03）/ ──── / 在面板中显示 / 取消钉住 ⌘W。
- 选项绑定统一 `optionBinding(keyPath)`（改副本 → onOptionsChange → 仓储回环）；`StickyCardPanel.apply(options:)` 即时生效（level/collectionBehavior），颜色/字号随渲染。
- "在面板中显示"：`PanelModel.locateNote(uuid:)`（切便签 + 1.5 秒高亮，同搜索定位语义）；AppDelegate 接 `showInPanelHandler`（开面板 + 定位，组合方式同通知定位）。
- 菜单打开期间的隐藏抑制暂靠 hover + `.common` tick；原生 NSMenu 化与显式 busy 记为后续打磨。

## 4.8 恢复与屏幕变化

- 启动恢复已在 4-2 落地（observeVisible 首帧即全量 create；软删除卡片由 SQL 排除）。
- 本故事补 `NSApplication.didChangeScreenParametersNotification`：全部卡片按当前所在屏可见区域钳制（CardGeometry.clampedFrame），位移过则持久化（actions.moveCard）。

## 4.10 全部显示/隐藏

- `CardManager.hideAllCards()/showAllCards()`：内存标记 `isHiddenAll`，orderOut/orderFrontRegardless；期间轮询暂停、新建卡片不显示（对账兜住）；重启后恢复显示（标记不持久化）。
- StatusMenu 右键菜单新增互斥项"隐藏所有卡片/显示所有卡片"（仅有卡片时出现）；AppDelegate 接四个闭包。
