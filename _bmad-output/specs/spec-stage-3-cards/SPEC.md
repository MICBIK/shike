# 阶段 3 · 钉在桌面（v0.3）

## Why

阶段 1/2 让便签和待办在菜单栏面板里形成了闭环，但内容仍然"藏"在面板里——想一直看着的几句话（今日三件事、正在跟进的结论）每次都要呼出面板才能看到。本阶段把便签"钉"成桌面卡片：常驻在桌面上、可调层级、可自动隐藏、点击穿透，颜色字号随用户选；卡片与面板是同一份数据的两个视图，实时同步。桌面卡片是拾刻名字的来源（"拾起一刻，钉在桌面"），也是产品从"菜单栏小工具"走向"桌面便签应用"的关键一步。

技术地基（阶段 0 已就位）：`stickyCard` 表（04 §5.4，noteId 唯一外键、位置/层级/颜色/字号/自动隐藏/空间等列齐全）、`NoteListItem.isPinnedToDesktop` 标记、启动顺序中的"恢复卡片"插槽（04 §6.1）。

## Capabilities

- **CAP-1** 技术验证（S3-00）
  - **intent:** 动手实现前，把卡片窗口的四个关键技术问题在真机上验证出结论，写进 ADR-025，避免后续故事在错误假设上返工。
  - **success:**
    - 结论一：卡片"隐藏 + `ignoresMouseEvents = true`（点击穿透）"时，能否用全局鼠标位置监听唤回卡片（对比 `NSEvent.addGlobalMonitorForEvents(.mouseMoved)` 与低开销的定时 `CGEvent`/`NSEvent.mouseLocation` 轮询两条路线，记录权限要求与 CPU 占用）；
    - 结论二：三档层级（`floating` = `.floating`、`normal` = `.normal`、`desktop` = 桌面层级）在多桌面空间、全屏应用、多显示器下的真实表现与所需 `collectionBehavior` 组合；
    - 结论三：`canJoinAllSpaces` 与 `fullScreenAuxiliary` 的组合矩阵，哪些组合能达成 03 §10.5 的"空间"子菜单语义；
    - 结论四：卡片"不抢焦点"（`styleMask` 去 `activatable` 或 `canBecomeKeyOnlyIfNeeded`）下，双击编辑仍能获得键盘焦点并输入中文（IME）；
    - 每条结论附最小复现/验证代码路径；ADR-025 记录选型与放弃项。
- **CAP-2** 钉出与收回（S3-01）
  - **intent:** 便签右键"钉到桌面"出现卡片；卡片可关闭；删除/撤销与卡片联动。
  - **success:**
    - 便签右键菜单新增"钉到桌面"；新卡片默认 240×180，出现在面板所在屏幕中央偏上，与已有卡片重叠时依次错开 24 pt（L2 纯函数定位）；
    - 卡片显示便签全文（当前字号），顶部操作条 hover 出现：左侧拖动区、右侧层级按钮、⋯、✕；
    - 卡片可钉多张（多张便签各自钉出）；面板中已钉便签显示图钉标记（`isPinnedToDesktop` 已在观察流中）；
    - ✕ / ⌘W / 菜单"取消钉住"关闭卡片，便签保留（删 `stickyCard` 记录）；
    - 删除已钉便签：卡片消失；撤销删除：卡片恢复（重钉）；便签软删除期间卡片记录保留不显示（04 §5.4 规则，L2 验证）；
    - 一张便签最多一张卡片（noteId 唯一约束，重复钉出走更新不报错）。
- **CAP-3** 显示层级（S3-02）
  - **intent:** 每张卡片可选浮在最上层 / 普通窗口 / 贴在桌面层。
  - **success:** `level` 列三值映射 NSWindow.Level（CAP-1 结论二的具体参数）；每张卡片单独设置（卡片菜单"层级"子菜单 + 层级按钮循环切换）；新卡片默认值来自 `card.default.level`（默认 floating）；设置-卡片分页真实化（默认层级、颜色、字号、自动隐藏、延迟、不透明度、空间、全屏，与 03 §9 对齐）；层级为持久化列，重启恢复。
- **CAP-4** 自动隐藏（S3-03）
  - **intent:** 卡片在鼠标离开后淡出，需要时唤回；隐藏时不挡操作。
  - **success:**
    - 每张卡片可开关（默认关）；鼠标离开满 N 秒淡出（0.3 秒）到隐藏不透明度（0%–60%，默认 20%）；隐藏中点击穿透（`ignoresMouseEvents`）；
    - 鼠标回到卡片区域停留 0.2 秒淡入（0.15 秒）——唤回机制按 CAP-1 结论一选型；
    - 编辑中、菜单打开、拖动/调整大小中不隐藏；
    - N：1 / 3（默认）/ 5 / 10 秒；全部持久化；遵循"减弱动态效果"（淡出淡入改直切）。
- **CAP-5** 外观（S3-04）
  - **intent:** 卡片长得像便签纸：颜色、字号、圆角阴影可调。
  - **success:** 六色预设（黄默认/绿/蓝/粉/紫/灰）明暗各一套色值（03 §15）；字号小/中（默认）/大；圆角 10 pt + 阴影；拖边缘/角调整大小，最小 160×100（钳制纯函数 + 持久化）；全部持久化，重启恢复。
- **CAP-6** 空间与全屏（S3-05）
  - **intent:** 卡片显示在哪些空间、是否压在全屏应用之上，由用户选。
  - **success:** 每张卡片：所有空间（默认，`canJoinAllSpaces`）/ 仅所在空间（`moveToActiveSpace` 语义，按 CAP-1 结论三落实）；显示在全屏应用之上（默认否，`fullScreenAuxiliary`）；设置即生效并持久化；验收按 02 阶段 3 清单"切换桌面空间"项执行。
- **CAP-7** 卡片上编辑（S3-06）
  - **intent:** 双击卡片直接改正文，与面板实时同步。
  - **success:** 双击进入编辑（不抢焦点前提下获得键盘焦点与 IME，CAP-1 结论四）；点击外部或 Esc 结束；停止输入 0.5 秒自动保存（同面板防抖）；卡片与面板同一便签双向实时同步（同一观察流，两侧无私有副本）；编辑中卡片不隐藏（CAP-4）。
- **CAP-8** 恢复与屏幕变化（S3-07）
  - **intent:** 重启后卡片原地恢复；显示器变化后卡片不掉出屏幕。
  - **success:** 启动时按 `stickyCard` 记录恢复全部卡片（位置、大小、层级、颜色、字号、自动隐藏、空间设置；接入 04 §6.1 启动顺序"恢复卡片"插槽）；显示器断开/分辨率变化后，出屏卡片自动移回可见区域（钳制函数，L2 用例覆盖"完全出屏/部分出屏/多屏切换"）；便签软删除期间的卡片记录不恢复显示（CAP-2 规则）。
- **CAP-9** 卡片菜单（S3-08）
  - **intent:** 卡片右键集中全部设置，与面板右键能力对齐。
  - **success:** 菜单结构按 03 §10.5：编辑 / 颜色▸ / 字号▸ / 层级▸ / 自动隐藏▸（开启✓、延迟▸、隐藏后不透明度▸）/ 空间▸（所有空间、仅当前空间、显示在全屏应用之上✓）/ ──── / 在面板中显示 / 取消钉住 ⌘W；"在面板中显示"= 呼出面板、切便签模式、定位该便签；菜单打开期间不自动隐藏；所有项即时生效并持久化。
- **CAP-10** 全部显示/隐藏（S3-09）
  - **intent:** 一键把所有卡片收起来再放出来，不改任何设置。
  - **success:** 菜单栏右键菜单新增"隐藏所有卡片 / 显示所有卡片"（互斥显示）；临时隐藏不改变卡片设置与数据库；重启后恢复显示状态。

## Constraints

- **沿用阶段 0/1/2 全部硬约束：**模块边界与导入检查（CI checks）；ShikeKit 不引入 AppKit/SwiftUI；无单例、依赖注入；错误只抛 `ShikeDataError`、不 `try?` 吞写入；文案键集中 xcstrings（`extractionState: manual`）；"警告即错误"只在 CI（ADR-019）；GPL 文件头；新文件先 `xcodegen generate`。
- **无 schema 迁移：**`stickyCard` 表阶段 0 建好（04 §5.4），本阶段纯功能开发；若 CAP-1 验证发现必须加列（预期不需要），先按 06 流程补迁移评审再动。
- **卡片窗口层（App 层）：**`NSWindow` 子类/配置 + NSHostingView 或 NSView 均可，选型由 CAP-1 结论定；卡片控制器由 AppEnvironment 组装注入，不出现单例；卡片数量上限不做硬限制，但恢复与监听须按"存在几张建几张"惰性管理（NFR 性能）。
- **数据同步唯一通道：**卡片与面板都只消费 `NoteRepository.observeActive()` 与 `StickyCardRepository` 观察流，禁止各自持有第二份真相；写路径全部走仓储。
- **坐标约定：**`stickyCard.x/y/width/height` 为屏幕坐标（左下角原点，AppKit 一致）；跨屏与空间切换的坐标换算集中在纯函数（L2 可测），不做隐式全局状态。
- **权限边界：**CAP-4 唤回监听若需要"输入监控"类 TCC 授权，须在 CAP-1 中给出替代方案或明确的授权引导；**任何 TCC 授权一律由用户亲手授予**（ADR-021 同款约束），设置页给说明。
- **新偏好键：**`card.default.level`（floating）/ `card.default.color`（yellow）/ `card.default.fontSize`（medium）/ `card.default.autoHide`（false）/ `card.default.hideDelay`（3.0）/ `card.default.hiddenOpacity`（0.2）/ `card.default.allSpaces`（true）/ `card.default.showOverFullScreen`（false），集中 `Preferences.Key` 注册并同步 04 §5.5。
- **动效：**淡入淡出经 `Motion` 辅助，系统"减弱动态效果"开启时直切（与 ADR-022 动效包一致）。
- **验收基线：**层级/空间/全屏/穿透等窗口系统行为归 L3 真机验收（02 清单）；L1/L2 覆盖定位错开、钳制、恢复映射、持久化读写、联动规则（删除/撤销/取消钉住）、自动隐藏状态机（注入时钟与鼠标位置）。

## Non-goals

- 待办不能钉卡片（只有便签；02 阶段 3 目标即"便签可以钉成桌面卡片"）。
- 卡片 Markdown 渲染、富文本、图片（"以后再说"清单）。
- 卡片间的对齐吸附、分组、批量框选。
- 多张便签合并/拆分；便签与待办互转（S5-03）。
- 阶段 3.5 主窗口（v0.4，ADR-023）——本阶段结束后另开规划。
- 卡片自定义主题色/用户自选色值（ADR-024 同款边界：预设六色起步）。
