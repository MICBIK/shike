## 1. GitHub Release 文案（草案，可整段粘贴）

> 标题建议：**拾刻 v0.4.0 · 朋友内测第一版**
> 适用口径：面向内测朋友的可读介绍；不写内部阶段编号故事（放 §2 版本历程）。占位符以【】标注。

---

**拾刻（Shike）** 是一个住在 macOS 菜单栏的随手记工具：想到什么，按 ⌥N 立刻记下来；写了时间（比如"明天上午十点取快递"）就自动到点提醒；重要的便签还能钉在桌面上常驻。全部数据存在你自己电脑本地，不联网、不上传。

**这个版本里有什么**

- **快速随手记**：⌥N 呼出即打字，回车保存；拼音打字到一半按回车只上屏不误提交；⇧↩ 换行。便签、待办两种模式，输入一半关掉草稿也在。
- **中文时间识别**：待办里直接写"周五下午三点交报告"，时间自动识别并高亮，到点系统通知提醒；可以"稍后提醒"、可以在通知上直接标完成。识别不了的时间（比如"有两点需要注意"）不会误伤。
- **桌面卡片**：便签可以钉在桌面上，三种层级（永远在最上 / 普通窗口 / 沉在桌面），可调透明度、自动隐藏、跟随所有桌面空间或固定在原空间、多显示器下自动回到可见区域。
- **主窗口**：菜单栏图标右键 →「主窗口」。便签、待办、回收站三区一览；⌘F 搜索；删除有 5 秒撤销条，误删能找回；支持导出 Markdown / JSON。
- **数据安全**：本地 SQLite 存储，每日自动备份，回收站可恢复；保存失败会如实提示并可重试，不静默丢内容。

**数据与隐私**

- 所有数据与备份都在本机 `~/Library/Application Support/Shike`（备份在其 `Backups/` 子目录）。
- App 无任何网络行为。若首次启动弹出"本地网络"权限询问，选"拒绝"即可，不影响任何功能。

**已知限制（如实告知）**

- **首次打开需放行**：App 尚未做公证，首次打开会被 Gatekeeper 拦截。做法：在【下载方式：dmg / 压缩包——待规划会话定】中把拾刻拖入"应用程序"后，**右键点图标 → 打开 → 再点"打开"**；若仍被拦，到 系统设置 → 隐私与安全性 → 点"仍要打开"。不同 macOS 版本界面略有差异（macOS 15 及更早为"仍要打开"按钮位置不同）。
- **关于页版本号显示 0.0.0（1）**：正式版本号编排排在下一阶段（发布脚本）实现，本版以标签 v0.4.0 为准。
- 删除撤销条 5 秒后自动消失，属当前设计；体感反馈欢迎提出。
- 拾刻没有 Dock 图标：启动后在菜单栏图标里，右键它可打开面板 / 主窗口 / 设置。

**反馈**
