## 2. 拾刻的定位坐标

菜单栏呼出捕捉 + **中文时间识别** + **桌面卡片** + 便签待办一体 + **本地私密/免费/开源**。没有任何一个竞品同时占住这三条斜体——每家最多占一条半。

## 3. 拾刻的优点（对照后成立的差异化）

1. **中文时间识别的深度是硬差异。** 系统提醒事项有中文日期检测但只是"输入后弹出建议点一下"，Todoist 的中文 NLP 仅覆盖"每周五"类循环表达；拾刻是边输入边高亮、05 规格级精确解析（相对时长/下周/周末/歧义规则）、可 ✕ 取消、已过时刻红字警示、识别结果进提醒调度——把"说一句话就定好时间"做成了完整闭环。这是与所有竞品拉开差距最实的一项。
2. **桌面卡片的可配置深度无对手。** Stickies 只有浮动窗口；SideNotes 是边缘抽屉（另一种范式）；小黄条功能最像但**没有 Mac 客户端**。拾刻的每卡独立设置（三种层级/自动隐藏+透明度+点击穿透/空间与全屏规则/颜色字号）在 macOS 便签类里是最深的，且中文市场的直接竞品恰好缺席 Mac。
3. **本地私密 + 免费 + 开源，在订阅泛滥的市场里是清晰卖点。** 对标产品几乎全是订阅制（滴答 ¥139/年、Todoist ~$48/年、flomo Pro ¥99/年）或买断（Tot $30、Things $50）；拾刻无账号无遥测、数据不出本机、GPL 开源。对隐私敏感用户和"不想再订一个订阅"的用户，这是决策性理由。
4. **捕捉系统工程化。** 呼出即打字不丢字（typing buffer）、草稿跨收起保留、IME 组合态安全、⌘Z 撤销闭环、三面编辑互斥——"3 秒记一条"是被当成系统属性打磨的，竞品的速记类（Tot/Antinote）没有待办提醒管线，任务类（Things/滴答）呼出捕捉的顺滑度普遍不如专职速记。
5. **便签+待办+桌面卡片一体且轻。** flomo 没有提醒，提醒事项没有便签卡片，Tot 没有待办；拾刻一个小 app 把三件事闭环（记 → 钉 → 到点提醒）。

## 4. 拾刻的不足（按对用户决策的影响排序）

1. **单机单端，无同步无移动端**（影响最大的差距）。全部竞品都有 iCloud/云同步+手机端（Tot、滴答、flomo、提醒事项）；拾刻一台 Mac 换机要靠导出/备份手工迁移。注：这是 01 §5.3 的既定取舍（云同步在第二平台之后），不是遗漏——但营销与引导必须把"本地私密"讲成选择而不是缺陷。
2. **无自动化接口**。滴答有 URL Scheme 文档页、Things 有 AppleScript、提醒事项有 Siri+快捷指令、flomo 有微信服务号输入；拾刻没有任何外部触发面（无 URL Scheme/Shortcuts/AppleScript）。这是**便宜的补齐项**（阶段 4/5 可排），补上后能进 Power User 的工作流。
3. **提醒深度**。滴答的重复规则/自定义稍后/持续提醒、提醒事项的循环提醒都强于拾刻的一次性提醒+固定档稍后（5–60 分钟）。重复待办在 1.0 明确不做清单里——保持，但这是用户从滴答迁来时最先问的问题。
4. **组织能力弱**。无标签/清单/文件夹（flomo 多级标签、Things 项目+区域、滴答清单+智能筛选）。拾刻靠搜索+分组撑着，1.0 冻结不做——竞品对比下，长_depth 用户会感到天花板，阶段 5+ 候补。
5. **输入形态单一**。纯文本；flomo 有语音/图片/微信输入，Stickies 有图形。与"富文本不做"同样属既定取舍。
6. **无导入迁移路径**。有导出（md/json）没有"从 Stickies/提醒事项/滴答导入"。对新增用户是摩擦项，属增长型功能，阶段 4/5 未排期——建议列为 idea。
7. **无 AI**。2026 年市场 flomo Max 已有 AI 关联笔记、评测圈以"有无 AI"打分（Things 3 因无 AI 被点名）。拾刻的"本地/轻"原则与云端 AI 冲突，维持不做，但要意识到评测话语权会受影响。
8. **分发成熟度**。竞品全是签名+公证的一键安装；拾刻 v0.4 仍是 ad-hoc + 用户手动放行（阶段 4 S4-00~S4-03 正是补这个）。

## 5. 对战略的启示

1. **身份要打三角**：中文说时间 → 钉在桌面 → 本地免费。宣传与首次引导（S4-08）都应围绕它，尤其要把"系统提醒事项也认识中文日期"的场景差异（边写边高亮/可反悔/到点调度）演示出来。
2. **Mac 桌面卡片的中文市场窗口是开的**：小黄条们没有 Mac 端，Stickies 太弱——这是拾刻最容易建立"品类第一"心智的地方。
3. **阶段 4/5 候补两个便宜项**：URL Scheme（对齐滴答/Things 先例）、导入向导（Stickies/提醒事项）。都进 idea，不进当前阶段。
4. **不追的**：云同步/移动端（触发条件未到）、AI（与本地轻冲突）、协作——维持 01 §5.2/5.3 的纪律。
