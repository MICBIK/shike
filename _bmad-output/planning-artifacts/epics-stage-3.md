# 拾刻 Shike - Epic Breakdown（阶段 3）

## Overview

本文件把拾刻阶段 3（钉在桌面）的需求拆成可以逐个实现的故事。需求来源（06 §8）：

| 通常的来源 | 拾刻的对应来源 |
|---|---|
| PRD | 阶段规格 `_bmad-output/specs/spec-stage-3-cards/SPEC.md` |
| 架构文档 | 规格伴随文件、docs/04（§5.4 stickyCard 表、§5.5 card.default.*、§6.1 启动顺序） |
| UX 文档 | docs/03 §10（桌面卡片全部小节）、§9（设置-卡片分页）、§15（卡片色值） |

阶段 3 是 Epic 4（阶段 N = Epic N+1，06 §8）。FR 编号延续阶段 2（FR76 起），NFR 延续 NFR24 起；阶段 0/1/2 的全部硬约束继续生效。路线图的 S3-xx 对应本史诗故事 4-x（4-1 = S3-00 技术验证）。

## Requirements Inventory

### Functional Requirements

**地基与钉出**

FR76：技术验证（CAP-1、S3-00）：卡片窗口的唤回监听选型、三档层级的真实表现、空间/全屏 collectionBehavior 矩阵、不抢焦点下的编辑与 IME 四个问题验证出结论，记 ADR-025；后续故事按结论实现。
FR77：钉出（CAP-2、S3-01）：便签右键"钉到桌面"创建 `stickyCard` 记录（默认值来自 `card.default.*`）；新卡 240×180，面板所在屏中央偏上，与已有卡重叠时依次错开 24 pt。
FR78：卡片窗口（CAP-2、S3-01）：显示便签全文；顶部操作条 hover 出现（左拖动区、右层级按钮、⋯、✕）；圆角 10 pt 带阴影；不抢焦点（点击不让拾刻变前台应用）。
FR79：收回（CAP-2、S3-01）：✕ / ⌘W / 菜单"取消钉住"删除卡片记录，便签保留；面板已钉便签显示图钉标记。
FR80：删除/撤销联动（CAP-2、S3-01）：删除已钉便签卡片消失，撤销删除卡片恢复；软删除期间卡片记录保留不显示；一张便签最多一张卡片。

**层级与外观**

FR81：显示层级（CAP-3、S3-02）：`floating`/`normal`/`desktop` 三档映射 NSWindow.Level（参数按 FR76 结论）；每卡单独设置；默认值偏好 `card.default.level`。
FR82：外观（CAP-5、S3-04）：六色预设（黄默认）明暗两套色值；字号小/中（默认）/大；拖边/角调整大小，最小 160×100；圆角阴影；全部持久化。
FR83：设置-卡片分页（CAP-3/4/5/6）：新卡片默认层级/颜色/字号/自动隐藏/延迟/不透明度/空间/全屏，与 03 §9 表一致。

**自动隐藏**

FR84：隐藏与唤回（CAP-4、S3-03）：鼠标离开满 N 秒（1/3 默认/5/10）淡出 0.3 秒到隐藏不透明度（0%–60%，默认 20%）；隐藏中点击穿透；鼠标回到卡片区域停留 0.2 秒淡入 0.15 秒；唤回监听按 FR76 结论选型。
FR85：不隐藏情形（CAP-4、S3-03）：编辑中、菜单打开、拖动/调整大小中不隐藏；"减弱动态效果"时淡入淡出改直切。

**空间与编辑**

FR86：空间与全屏（CAP-6、S3-05）：所有空间（默认）/ 仅所在空间；显示在全屏应用之上（默认否）；collectionBehavior 组合按 FR76 结论。
FR87：卡片上编辑（CAP-7、S3-06）：双击进入编辑（IME 可用），点击外部或 Esc 结束，停止输入 0.5 秒自动保存；与面板同一便签双向实时同步（同一观察流）。

**恢复与菜单**

FR88：启动恢复（CAP-8、S3-07）：按 `stickyCard` 记录恢复全部卡片（04 §6.1 插槽）；显示器断开/分辨率变化后出屏卡片移回可见区域。
FR89：卡片菜单（CAP-9、S3-08）：按 03 §10.5 全量子菜单（编辑/颜色/字号/层级/自动隐藏/空间/在面板中显示/取消钉住 ⌘W）；菜单打开期间不自动隐藏；即改即存。
FR90：全部显示/隐藏（CAP-10、S3-09）：菜单栏右键"隐藏所有卡片 / 显示所有卡片"互斥项；临时隐藏不入库，重启后恢复显示。

### 非功能需求

NFR24：卡片与面板单一数据源——两者都只消费仓储观察流，禁止第二份真相；卡片数量"存在几张建几张"，监听器全局共享一个。
NFR25：自动隐藏状态机为纯逻辑类型（注入时钟与鼠标在位信号），L2 全路径覆盖；唤回轮询/监听的常驻开销可忽略（FR76 结论记录实测 CPU）。
NFR26：坐标换算、错开定位、可见区域钳制全部纯函数（注入屏幕信息），L1/L2 直测；不依赖隐式全局状态。
NFR27：TCC 授权一律用户亲手授予；若唤回方案需要新授权，CAP-1 必须给出替代或引导方案。

### UX-DR 覆盖

本阶段交互以 03 §10（结构/操作/层级/自动隐藏/菜单/全部隐藏）、§9（卡片分页）、§15（色值）为准；文案遵循 03 §15。

## Epic List

### Epic 4: 阶段 3 · 钉在桌面

完成后，便签可以钉在桌面上一直可见：
- 右键一钉，便签变成桌面上的小卡片，可拖动、缩放、换色、调字号；
- 三档层级 + 自动隐藏 + 点击穿透，常驻但不挡事；
- 卡片和面板是同一份数据，改哪边都实时同步；
- 重启、拔显示器、切空间，卡片都待在该在的地方。

本史诗对应 02 中的 S3-00～S3-09 和阶段 3 的 8 条验收。

**覆盖的功能需求：**FR76～FR90（全部）。NFR24～NFR27 分配到各故事的验收标准中。

**实施说明：**
- 依赖顺序：4-1（技术验证，ADR-025）→ 4-2（钉出与收回，卡片骨架）→ 4-3（层级）/4-5（外观）可并行 → 4-4（自动隐藏，依赖唤回结论）→ 4-6（空间全屏）→ 4-7（编辑）→ 4-8（恢复）→ 4-9（菜单）→ 4-10（全部显示/隐藏）。
- 4-1 产出原型代码可直接演化为 4-2 的骨架，避免一次性代码。
- 每个故事按 bmad-build 的 oneshot 循环实现：实现 → L1/L2 测试 → checks → 独立盲审 → 台账 → 提交推送盯 CI。

## Epic 4 Stories

### Story 4.1: 技术验证——卡片窗口与唤回（S3-00）

作为实现卡片的人，
我希望在写正式代码前验证窗口层级、点击穿透、唤回监听和焦点策略，
以便后面的故事不在错误假设上返工。

**依据：**FR76；NFR25/27；SPEC CAP-1；docs/03 §10.3/§10.4；docs/04 §5.4。

**验收标准：**

1. 唤回结论：卡片 `orderOut`/透明 + `ignoresMouseEvents` 状态下，两条路线（全局 `.mouseMoved` 监听 vs 定时 `NSEvent.mouseLocation` 轮询）各记权限要求与实测 CPU 占用，选定一条写入 ADR-025。
2. 层级结论：三档层级在"多空间 + 全屏应用（Safari/音乐全屏）+ 双显示器"下的表现矩阵（哪些组合有效、哪些需要 `collectionBehavior` 补偿），参数写入 ADR-025。
3. 空间矩阵：`canJoinAllSpaces`/`moveToActiveSpace`/`fullScreenAuxiliary` 组合对照 03 §10.5"空间"子菜单语义，给出映射表。
4. 焦点结论：无 `.activatable` 的窗口双击后能获得键盘焦点并输入中文（IME 组合态正常上屏），否则给出替代方案。
5. 原型代码（可编译运行的最小卡片窗口 + 三档层级切换 + 唤回）留在实现分支，直接演化为 4-2 骨架。
6. ADR-025 落盘 docs/07（选型、放弃项、参数），02 的 S3-00 验收项可勾选。

### Story 4.2: 钉出与收回（S3-01）

作为使用便签的人，
我希望右键把重要便签钉到桌面上，不用时一键收回，
以便重要内容常驻可见。

**依据：**FR77～FR80；NFR24/26；scope-boundaries（CardManager/StickyCardController）；docs/03 §10.1/§10.2；docs/04 §5.4/§6.1。

**验收标准：**

1. 便签右键"钉到桌面"：创建 `stickyCard` 记录，卡片出现在面板所在屏中央偏上；与已有卡重叠时依次错开 24 pt（定位纯函数 L2：首张、第 2/3/4 张、环绕回卷）。
2. 卡片显示便签全文（当前字号）；hover 顶部操作条（拖动区、层级按钮、⋯、✕）；圆角 10 pt 阴影；点击卡片拾刻不变前台（L3 真机，L2 断言 styleMask 无 `.activatable`）。
3. 拖动顶部操作条移动卡片，松手持久化 x/y（L2 换算纯函数；L3 真机）。
4. ✕ / 菜单"取消钉住"删除卡片记录，便签保留；已钉便签面板行显示图钉标记。
5. 删除已钉便签：卡片消失；撤销删除：卡片恢复（CardManager 对账，L2：软删除隐藏/恢复显示/永久删除级联）。
6. 同一便签重复钉出走更新不报错（noteId 唯一）。
7. 卡片与面板单一数据源：卡片内容跟随便签观察流实时更新（L2：改内容卡片变）。

### Story 4.3: 显示层级（S3-02）

作为使用卡片的人，
我希望每张卡片自己选"永远可见 / 普通窗口 / 贴桌面"，
以便不同重要程度的内容互不干扰。

**依据：**FR81；NFR26；ADR-025 层级结论；docs/03 §10.3；docs/04 §5.5。

**验收标准：**

1. 三档层级映射 ADR-025 参数；切换即时生效（L2 断言 window.level；L3 按 02 验收"三种层级"项）。
2. 卡片操作条层级按钮循环三档；卡片菜单"层级"子菜单同功能。
3. `level` 列持久化，重启恢复（L2 读写往返）。
4. 新卡片默认值 `card.default.level`（默认 floating）；设置-卡片分页可改（L2 断言写入偏好）。

### Story 4.4: 自动隐藏（S3-03）

作为使用卡片的人，
我希望卡片在不用时自动淡化、不挡操作，鼠标回去又出现，
以便桌面干净、卡片常驻但不碍事。

**依据：**FR84～FR85；NFR25；ADR-025 唤回结论；docs/03 §10.4。

**验收标准：**

1. `AutoHideStateMachine` 纯逻辑 L2 全路径：显示→(离开满 N)→淡出→隐藏→(悬停 0.2s)→淡入→显示；编辑/菜单/拖动期间强制显示中；参数注入（时钟/迟滞）。
2. 隐藏中 `alphaValue` = hiddenOpacity 且 `ignoresMouseEvents = true`（点击穿透，L3 按 02 验收"0% 不透明度"项）；淡出 0.3s/淡入 0.15s，"减弱动态效果"直切。
3. 唤回按 ADR-025 选型实现；共享单监听器；常驻 CPU 实测值记入 ADR-025。
4. 每卡开关 + N（1/3 默认/5/10）+ 隐藏不透明度（0–60%）可设并持久化；卡片菜单与设置-卡片分页（新卡默认）两处入口。
5. 开关默认关；关闭后状态机退化为常显。

### Story 4.5: 卡片外观（S3-04）

作为使用卡片的人，
我希望卡片有颜色和字号、能缩放，
以便它像一张真正的便签纸。

**依据：**FR82；NFR26；docs/03 §10.1/§15；docs/04 §5.5。

**验收标准：**

1. 六色预设（黄默认/绿/蓝/粉/紫/灰）明暗两套色值按 03 §15 落 Assets 或常量表；切换即生效持久化（L2 往返；L3 真机看色）。
2. 字号小/中（默认）/大三档；卡片内容随字号重排。
3. 拖边缘/角调整大小，最小 160×100（钳制纯函数 L2）；宽高持久化。
4. 圆角 10 pt + 阴影常在；新卡默认色/字号来自偏好，设置-卡片分页可改。

### Story 4.6: 空间与全屏（S3-05）

作为多桌面与全屏用户，
我希望卡片跟我在哪个空间、要不要压在全屏上面，由我定，
以便卡片出现在我期望的地方。

**依据：**FR86；ADR-025 空间矩阵；docs/03 §10.5。

**验收标准：**

1. "所有空间"（默认）卡片在任意空间可见；"仅所在空间"卡片留在原空间（collectionBehavior 按 ADR-025 映射表；L3 按 02 验收"切换桌面空间"项）。
2. "显示在全屏应用之上"开关（默认否）：开时卡片浮在全屏应用上（`fullScreenAuxiliary`）。
3. 设置即生效、持久化（L2 往返）；卡片菜单"空间"子菜单与设置分页同源。

### Story 4.7: 卡片上编辑（S3-06）

作为使用卡片的人，
我希望双击卡片直接改正文，面板里同步变，
以便两边随便改、不用来回找。

**依据：**FR87；NFR24；docs/03 §10.2。

**验收标准：**

1. 双击内容区进入编辑（无 `.activatable` 下获得键盘焦点、IME 正常，ADR-025 结论）；点击外部或 Esc 结束编辑。
2. 停止输入 0.5 秒自动保存（防抖参数同面板）；编辑失败输入保留（-ShikeSimulateWriteFailure L2）。
3. 双向同步：卡片改、面板列表变；面板改、卡片变（同一观察流，L2 两次注入断言）。
4. 编辑中不自动隐藏（状态机输入信号）；Esc 结束编辑优先于其他 Esc 语义。

### Story 4.8: 恢复与屏幕变化（S3-07）

作为重启或拔显示器的用户，
我希望卡片们原地回来、不掉出屏幕，
以便配置一次就不用管。

**依据：**FR88；NFR26；docs/04 §6.1/§5.4。

**验收标准：**

1. 启动恢复：按 `stickyCard` 记录重建全部卡片（位置/大小/层级/颜色/字号/自动隐藏/空间设置），接入 04 §6.1 "恢复卡片"插槽（L2：记录→窗口参数映射；L3 按 02 验收"退出重开"项）。
2. 软删除便签的卡片记录不恢复显示（对账过滤）。
3. `didChangeScreenParametersNotification` 后全部卡片重钳制入可见区域（钳制纯函数 L2：完全出屏/部分出屏/多屏切换三用例；L3 按 02 验收"断开外接显示器"项）。

### Story 4.9: 卡片菜单（S3-08）

作为使用卡片的人，
我希望右键卡片就能改它的一切设置，
以便不用回设置窗口。

**依据：**FR89；docs/03 §10.5。

**验收标准：**

1. 菜单结构与 03 §10.5 一致：编辑 / 颜色▸ / 字号▸ / 层级▸ / 自动隐藏▸（开启✓、延迟▸、隐藏后不透明度▸）/ 空间▸（所有空间 / 仅当前空间 / 显示在全屏应用之上✓）/ 分隔线 / 在面板中显示 / 取消钉住 ⌘W。
2. 各项即时生效并持久化；✓ 状态与当前值一致（L2 断言状态映射）。
3. "在面板中显示"：呼出面板、切便签模式、定位并高亮该便签（复用 locateNoteID，L2 回调断言）。
4. 菜单打开期间不自动隐藏；关闭菜单恢复状态机。

### Story 4.10: 全部显示与隐藏（S3-09）

作为桌面被卡片占满的人，
我希望一键把所有卡片收起来、再一键放出来，
以便临时要一块干净桌面。

**依据：**FR90；docs/03 §10.6。

**验收标准：**

1. 菜单栏右键新增"隐藏所有卡片 / 显示所有卡片"互斥项（无卡片时灰置或隐藏入口）。
2. 临时隐藏不改变卡片设置与数据库（隐藏态为内存标记，L2：隐藏→恢复后各项设置不变）。
3. 重启后卡片恢复显示（内存标记不持久化）。
4. 隐藏期间自动隐藏状态机不启动（避免隐藏叠加隐藏）。

### Story 4.11: 桌面层卡片可点击修复（S3-11，ADR-026）

作为把便签贴在桌面的人，
我希望能直接点卡片上的按钮来操作它，
而不是看得见点不着。

**依据：**ADR-025 结论 2 的层级目视验证不充分（未验证点击投递）；ADR-026；用户真机否决反馈（2026-09-29）。

**验收标准：**

1. 桌面层取 `CGWindowLevelForKey(.desktopIconWindow)`（ADR-026 决策 1，L2 断言三档层级映射值）。
2. 桌面层卡片可见且可点：壁纸之上、与桌面图标同层；工具栏各按钮（编辑/颜色/层级/⋯/✕）在桌面层可直接点击（L3 真机）。
3. 层级切换后 z 序正确：桌面↔普通↔置顶互切，卡片立即出现在新层级该在的位置（`orderFrontRegardless`，L3 真机）。
4. 换层级的写路径走 updateOptions（含失败上报与重试），与卡片菜单一致（L2 回调断言）。
5. 已知取舍入文档：桌面层卡片会挡住其正下方桌面图标的点击（ADR-026）。

### Story 4.12: 常驻工具栏与调整大小（S3-12，ADR-026）

作为使用卡片的人，
我希望常用操作就在卡片顶部的工具栏里，正文永远不被工具栏挡住，
以便不用猜交互、不用先悬停再找按钮。

**依据：**ADR-026；docs/03 §10.1/§10.2/§10.5（已修订）。

**验收标准：**

1. 顶部工具栏常驻：永远占位、永远可点（不依赖悬停出现）；悬停只改变按钮组亮度（55%→100%）（L3 真机）。
2. 正文永远从工具栏下方开始（固定 2 pt 呼吸），显示/隐藏、悬停与否、进入/退出编辑都不遮挡、不跳动（L2 不可测布局，代码评审 + L3 目视）。
3. 工具栏顶层按钮：编辑（铅笔/✓ 随编辑态切换）、颜色（按钮即当前色板，六色菜单）、层级（菜单显式三选，图标随层级：置顶/普通/桌面）、⋯、✕；循环按钮与 CardTheme.nextLevel 一并下线。
4. 右下角调整大小把手：拖拽实时改变卡片大小、实时钳制最小 160×100；松手按可见区域钳制并持久化（复用 onMove，L2：clampedResize 既有测试回归 + L3 真机拖拽手感）。
5. ⋯ 菜单结构与修订后的 03 §10.5 一致（字号/自动隐藏/空间/在面板中显示/取消钉住 ⌘W）。
6. 所有新交互控件带 hover 提示文案（复用既有本地化键，不新增键）。
