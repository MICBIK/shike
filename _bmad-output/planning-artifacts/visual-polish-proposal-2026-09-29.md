# 视觉打磨提案（2026-09-29）——基于竞品截图调研

状态：**配色已选定（2026-09-29 产品负责人）：青绿方案（原方案 C）**；并追加决定：全 App 图标去 emoji、统一用 SF Symbols（矢量质感）。其余动效与结构项默认照准。交互对比页：`_bmad-output/planning-artifacts/visual-compare-2026-09-29.html`（青绿为默认版本）。
调研素材：`/tmp/shike-visual-ref/`（Raycast ×3、Todoist ×2、Things 3、Tot、flomo、拾刻面板实拍）。

## 1. 现状诊断（拾刻面板实拍结论）

对照 `shike-panel-crop2.png`（2026-09-29 03:14 实拍）：

1. **零视觉身份**：工程里连 AccentColor 资产都没有（`Resources/` 只有 Localizable.xcstrings），面板是"系统默认灰 popover + 默认蓝分段控件 + 黑字灰字"，与系统任何一个 popover 无法区分。
2. **输入区无实体感**：只有一根光标悬在平面上，没有输入框的底色/圆角/边界——"这是个能打字的地方"全靠 placeholder 文案传达。
3. **列表零层次**：条目直接贴在 popover 平面上，无 hover、无行内边距节奏、无分隔语义，空白区一大片没有视觉锚点。
4. **零动效**：全 Panel 目录无一处 withAnimation/transition，所有状态硬切。
5. **识别高亮不可感知**：强调色 30% 透明度垫在材质上，浅色模式下淡蓝雾、深色模式下几乎不可见。

## 2. 竞品逐例拆解（看到了什么）

### Todoist（快速添加）——识别交互的直接标杆
- 输入框内被识别的文字：**饱和色药丸背景**（深色主题：深红底白字；浅色主题：浅红底深字），一眼可见且可点击。
- 输入框下方**解析结果 chip 行**：`[📅 8 Dec 09:00 ⟳ ×]`，图标 + 解析值 + 移除按钮，带描边圆角。
- 启示：拾刻的"下方灰色小字提示条"应升级为 **chip**；输入内高亮应换**饱和色调药丸**，而不是背景垫色。

### Raycast（主窗口 / 剪贴板）——"精致感"的机械拆解
- 列表行：主文字 + **右侧对齐的次级元数据**（类型、快捷键），行高紧凑但内边距充足。
- **section 标签**（"Suggestions"、"Today"）小号灰字大写，节奏感强。
- **底部操作栏**：左侧上下文（图标+名称），右侧**键帽芯片**（"⏎ 粘贴"、"⌘ K 操作"）——把"你能按什么键"永远摆在眼前。
- 选中行 = 全宽圆角灰底。
- 启示：拾刻撤销条可借这个形态（左摘要、右"撤销 ⌘Z"键帽）；列表时间戳可考虑右对齐；空态/分组标题用小标签。

### Things 3——克制与层级
- 大留白、粗黑任务标题、彩色但极小的图标、蓝色只给可交互元素。
- 启示：**颜色要少**。一个品牌色 + 语义色（逾期红/完成灰/警告黄），其余全靠灰阶层次。

### Tot——单一暖色身份
- 整体奶油纸色 + 琥珀文字 + 染色底栏，像一张纸便签，身份极强。
- 启示：小而美的工具靠**一个主色调**建立记忆点，拾刻可走同路线。

### flomo——绿色身份 + 卡片
- 品牌绿贯穿选中态、标签、统计数字；memo 卡片有轻微底色分层；日期小灰字。
- 启示：卡片化或行底色分层能解决"列表贴平面"的问题。

## 3. 提案

### 3.1 品牌色：拾刻青绿（2026-09-29 已选定）

负责人在四版本交互对比（A 现状 / B 琥珀 / C 青绿 / D 极简系统色）中选定**青绿**（冷色身份，flomo 路线；与 Todoist 红、Things 蓝、Bear 橙错开）。

- **Teal 600 `#0D9488`**（浅色模式主交互）
- **Teal 400 `#2DD4BF`**（深色模式主交互，暗底上够亮）
- **药丸/chip 背景**：浅色 `rgba(13,148,136,0.14)`；深色 `rgba(45,212,191,0.22)`
- **药丸/chip 文字**：浅色 `#0F766E`；深色 `#5EEAD4`
- 语义色不动：逾期红 `systemRed`、完成灰、警告黄。
- 分段控件、焦点环、选中态过青绿 tint。
- 落点：新建 `Assets.xcassets`（AccentColor 青绿色集，浅深两态）+ project.yml 注册 + Panel 根部 `.tint(...)`。

### 3.2 识别交互（S2-01 观感强化，对齐 Todoist）

1. 输入内高亮：背景垫色 → **琥珀药丸**（圆角 3px 背景，文字 medium 加重）。实现仍走 `CaptureTextView.applyHighlight` 的 `.backgroundColor`，把颜色换成琥珀色集并加 `NSBackgroundColorAttributeName` 圆角需 layoutManager 自绘——第一版用纯色块即可，圆角列为可选加强。
2. 提示条 → **chip 行**：`[🕒 周五 15:00 提醒 ×]`，描边圆角 chip，日期部分琥珀加粗，已过时间用红色变体；位置仍在输入框下方。
3. chip 出现加 0.15s 弹入。

### 3.3 撤销条重构（S1-07 反馈闭环）

对齐 Raycast 底栏形态：
- 删除：左 `已删除「前12字…」`，右键帽样式 `撤销 ⌘Z`。
- **恢复成功后切换视角**：`已恢复「…」✓`（中性琥珀 tint），独立 5 秒计时；栈非空时附 `还可撤销 N 条`。
- 修复：恢复失败重试时 `deletedStack` 回栈顺序错乱（append 到队尾 → 应回原位）。
- 条出入场加滑动淡入淡出。

### 3.4 输入区实体化

- 快速输入框包进圆角容器（quaternary 底色 + 6px 圆角 + 聚焦时 1px 琥珀描边），左右 12px 内边距。
- 输入文字 15px；placeholder 保持。

### 3.5 列表节奏

- 行 hover 底色（quaternary，圆角 6px），提示可右键/可点。
- 行内边距统一 12px 水平 / 8px 垂直；时间戳 11px tertiary。
- 便签行次行时间戳与内容间距收紧（2px → 视觉分组更清晰）。
- 待办分组标题：小号灰字标签（对齐 Raycast section label）。

### 3.6 动效（全 Panel）

| 场景 | 动效 | 时长 |
|---|---|---|
| 提示条/chip/撤销条出入场 | 滑动+淡入淡出 | 0.15s |
| 新条目插入列表 | 行淡入+轻微上移 | 0.2s |
| 待办勾选完成 | 划线从左到右 + 1s 后行淡出移组 | 0.3s/0.25s |
| 新条目 1 秒高亮 | 淡出而非硬灭 | 0.3s |
| 搜索进出 | 交叉淡化 | 0.15s |
| 面板呼出内容 | 整体淡入 | 0.12s |

- 尊重"减弱动态效果"（`NSWorkspace.accessibilityDisplayShouldReduceMotion`）：全部动效降级为纯淡入或直切。

### 3.7 图标规范（2026-09-29 追加决定）

全 App 界面图标统一 **SF Symbols**（矢量、自动适配粗细/深浅色），**禁用 emoji 作 UI 图标**：

- 识别 chip 的时钟：`clock`
- 空态图标：便签 `doc.plaintext`、待办 `timer`
- 搜索/关闭/转发等已有 SF Symbol 的保持并核对视觉重量
- 菜单栏状态图标若为 emoji/文字，改为 `timer` 模板图像（16–18pt）
- 组折叠箭头：`chevron.right` / `chevron.down`

### 3.8 不做（本轮明确排除）

- 不改面板材质为 hud/自带窗口阴影（popover 材质本身没问题，动起来再评估）。
- 不做主题/换肤。
- 不动菜单栏图标与设置窗口（除 tint 外）。
